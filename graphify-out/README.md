## ⚠ Do not move or rename this folder

`graphify-out` is hardcoded in the graphify package, not just the skill:

| Location | Path | Breaks if moved |
|---|---|---|
| `cache.py:48` | `graphify-out/cache/` | Re-spends the full extraction token cost |
| `detect.py:19` | `graphify-out/manifest.json` | `update` loses incremental change detection |
| `detect.py:244` | skip-list entry | **A moved copy gets ingested as source corpus** |
| `detect.py:351` | `graphify-out/memory/` | Saved query results stop feeding back in |

The third row is the real trap: relocating this to `docs/` would make the next run recreate
`graphify-out/` at the repo root *and* eat the old copy's `graph.json` as input, polluting the
graph with its own output.

## Keeping it current

```bash
graphify update .        # code changed → AST re-extract, no LLM, no API cost
/graphify . --update     # docs/papers/images changed → needs semantic re-extraction
/graphify . --cluster-only   # re-cluster an existing graph, no re-extraction
```

Use `graphify update .` after code edits. Reach for the `/graphify` slash-command form only when
`.md`/`.pdf`/image files changed, since that path dispatches extraction subagents and costs
tokens. The cache means unchanged files are never re-extracted either way.

## Build provenance

First build: 2026-08-09 · 96 files, ~1.29 M words → **1,027 nodes, 1,856 edges, 29 communities**
· 265,500 input / 111,900 output tokens · ~4.5 K tokens per query vs ~1.71 M naive (378× reduction).

Every edge carries a confidence tag — `EXTRACTED` (explicit in source), `INFERRED` (reasoned),
or `AMBIGUOUS` (flagged, not dropped) — plus a numeric `confidence_score`. Treat `AMBIGUOUS`
edges as questions, not facts; the report lists them under *Suggested Questions*.

Coverage caveat: the 20 code files were extracted by AST + semantic pass, but the numbers read
out of result *figures* by vision are as reliable as the figure labels. Two were flagged during
extraction as contradicting `memory.md` — see the AMBIGUOUS entries in `GRAPH_REPORT.md`.
